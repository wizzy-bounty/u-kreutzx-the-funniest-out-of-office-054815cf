Entry for the make.fun competition
[The Funniest Out-of-Office](https://make.fun/c/u-kreutzx-the-funniest-out-of-office-054815cf):
one line of an out-of-office auto-reply, the funniest I could make it.

The line hides from the inbox in a Wi-Fi-free cabin — and the fact that
you are reading the reply at all is the proof the cabin betrayed its
owner. One idea, one surprise, punchline at the end.

## Run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (and to `./output/entry.txt`
when run locally). Pure Python standard library, deterministic, no network.
